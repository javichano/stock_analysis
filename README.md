# Analizador de acciones

App hecha con Streamlit y yfinance para comparar ratios de valoración de varias
acciones (PER, PEG, márgenes, deuda, etc.), ver gráficos y consultar un glosario.

**Aviso:** proyecto educativo. Los datos vienen de Yahoo Finance y pueden ser
imprecisos. No es una recomendación de inversión.

## Ejecutar en local

    pip install -r requirements.txt
    python -m streamlit run app_acciones.py
